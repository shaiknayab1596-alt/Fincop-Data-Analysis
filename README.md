# Fincop-Data-Analysis

## Project Overview

This project analyzes digital payment trends across India using the PhonePe Pulse dataset. The data was extracted from the official PhonePe Pulse GitHub repository and transformed into structured datasets using Python. The analysis focuses on transaction volumes, transaction values, user growth across different states and time periods.

The project demonstrates end-to-end data analytics skills, including data extraction, data cleaning, transformation, exploratory data analysis (EDA), and interactive geographical visualization.

## Objectives

* Extract and process raw JSON data from the PhonePe Pulse repository.
* Analyze state-wise digital payment transactions across India.
* Study user growth and app adoption trends.
* Create interactive visualizations to identify regional payment trends.
* Generate business insights from transaction and user data.

## Technologies Used

* Python
* Pandas
* NumPy
* Plotly
* JSON
* Git & GitHub
* Jupyter Notebook / Google Colab

## Data Processing

* Cloned the PhonePe Pulse GitHub repository.
* Extracted transaction,  and user data from nested JSON files.
* Performed data cleaning and preprocessing.
* Converted raw data into structured Pandas DataFrames.
* Exported processed datasets into CSV format for further analysis.

## Key Analysis Performed

* State-wise transaction volume analysis
* State-wise transaction amount analysis
* User registration and app usage analysis
* Insurance transaction trend analysis
* Yearly and quarterly growth analysis
* Interactive India map visualization using Plotly Choropleth

## Key Insights

* Identified states with the highest digital payment activity.
* Analyzed transaction growth across different years and quarters.
* Examined user adoption patterns across regions.
